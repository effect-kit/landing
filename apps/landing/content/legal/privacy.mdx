effectkit.dev is the website and documentation for the Effect Kit packages, run by Effect Kit Contributors. It has no accounts, no ads and no sign-in.

## Summary

- No cookies. Nothing is stored in your browser for analytics.
- Your IP address is not kept by analytics.
- No session replay, no advertising, no data sold.
- Do Not Track is respected.

## Hosting

The site is hosted on Vercel. Like any host, Vercel processes your request and keeps standard server logs, which can include your IP address and user agent. See the [Vercel privacy policy](https://vercel.com/legal/privacy-policy "Vercel privacy policy").

## Analytics

We use PostHog (US cloud) to see how the site is used. It loads only on the production site, through a reverse proxy at `t.envoy1084.xyz`, and runs in cookieless mode. It sets no cookies and uses no local or session storage.

Visitors are counted with a privacy-preserving hash that PostHog's servers compute, instead of an identifier stored on your device. Your IP address is discarded once PostHog has derived your country from it. There are no personal profiles. If your browser sends Do Not Track, nothing is collected.

What is collected:

- Pages visited, referrer and campaign parameters.
- Approximate country, device type, browser and screen size.
- Performance metrics.
- Interactions with the site, such as copying code or install commands, text you copy, running a playground example, or searching the docs. Search queries are trimmed, and queries that look like an email address are replaced with a placeholder.
- Errors that happen in your browser.

## Requests from tools and agents

Requests for the Markdown pages, `llms.txt` and `llms-full.txt` do not run JavaScript, so the server counts them. Each count records the path and the requesting tool's user agent, grouped by tool family. It does not identify a person.

## Browser storage

The site stores two preferences in your browser's local storage so it can remember them: your theme, and your package manager choice for install commands. The playground also remembers whether its sound is on. These are not analytics, and they never leave your browser.

## Third parties

Fonts are served from this site, so no font provider sees your visit. The changelog pages fetch release notes from the public GitHub API on the server, and your browser does not contact GitHub. Links to other sites are covered by those sites' own policies.

## Changes

We can change this policy. The date at the top shows the last update.
