`@effect-kit/emails` gives Effect programs one `Email` service. You pick a provider by providing its Layer, and the same `email.send` call works with Resend, Amazon SES, Postmark, SendGrid and 12 others.

This walkthrough sends one message through Resend. Any other provider works the same way once its Layer is provided.

## Install the package and the Resend SDK

```package-install
@effect-kit/emails effect resend@6.34.1
```

## Set the API key

`Resend.layerConfig` reads `RESEND_API_KEY` by default.

```sh
export RESEND_API_KEY="your-resend-api-key"
```

## Write the program

**Example** (Sending a Message and Reading the Receipt)

```ts twoslash title="send.ts"
import { ConfigProvider, Effect, Layer } from "effect";
import { Email } from "@effect-kit/emails";
import * as Resend from "@effect-kit/emails/resend";

const EmailLive = Resend.layerConfig().pipe(
  Layer.provide(ConfigProvider.layer(ConfigProvider.fromEnv())),
);

const program = Effect.gen(function* () {
  const email = yield* Email;
  const receipt = yield* email.send({
    from: "hello@example.com",
    to: "ada@example.com",
    subject: "Welcome",
    text: "Your account is ready.",
  });
  console.log(receipt);
  //          ^?
});

Effect.runPromise(program.pipe(Effect.provide(EmailLive)));
```

Use a `from` address that is verified with the provider.

## Run it

```sh
node send.ts
```

```text
{
  provider: 'resend',
  status: 'accepted',
  references: [ { kind: 'providerMessageId', value: '...' } ]
}
```

<Callout type="warn" title="Accepted is not delivered">
  A receipt means the provider accepted the message. The package never sees delivery, bounces or
  opens.
</Callout>
