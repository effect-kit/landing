---
title: Installation
description: Install the package, one provider SDK at its pinned version, and React only if you render templates.
---

`@effect-kit/emails` needs Effect and the SDK of the provider you use. Every provider SDK is an optional peer dependency, so install exactly one.

## Requirements

- Node.js `>=24.22.0`.
- ESM only. The package has no CommonJS build.
- `effect@^4.0.6`. Snippets written for Effect v3 do not work.

## Install

**Example** (Installing the Package With Resend)

```package-install
@effect-kit/emails effect resend@6.34.1
```

Provider SDKs are pinned to exact versions. Install the version in the table below, not a range.

Importing a provider subpath without its SDK fails with `ERR_MODULE_NOT_FOUND`. The root `@effect-kit/emails` and `@effect-kit/emails/testing` need only Effect.

## React peers

Only [React templates](/docs/emails/react-templates) need React.

```package-install
@react-email/render@2.1.1 react@19.3.1 react-dom@19.3.1
```

```package-install
-D @types/react@19.3.0
```

<Callout type="info" title="Dev dependency">
  `@types/react` is a type-only peer. The renderer itself needs `@react-email/render`, `react` and
  `react-dom`.
</Callout>
