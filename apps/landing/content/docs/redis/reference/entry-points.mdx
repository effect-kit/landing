`@effect-kit/redis` has four entry points. The package is ESM only and its `exports` map has a `types` and a `default` condition for each. Import the root for services and types, then one runtime entry point for the layer.

| Entry point | Import                      | Use                                                                       |
| ----------- | --------------------------- | ------------------------------------------------------------------------- |
| `.`         | `@effect-kit/redis`         | Services, commands, errors and types. Runtime neutral, with no transport. |
| `./node`    | `@effect-kit/redis/node`    | `RedisNode` layers over `node:net` and `node:tls`.                        |
| `./bun`     | `@effect-kit/redis/bun`     | `RedisBun` layers over `Bun.connect`.                                     |
| `./upstash` | `@effect-kit/redis/upstash` | `RedisUpstash` layers over Effect HTTP, with SSE events.                  |

Pick one runtime entry point. See [Runtimes](/docs/redis/runtimes).

## `@effect-kit/redis`

### Services

Each service is a `Context.Service` class.

| Export                     | Kind    | Purpose                                                                                      |
| -------------------------- | ------- | -------------------------------------------------------------------------------------------- |
| `Redis`                    | Service | Ordinary commands, `pipeline`, `transaction`, `execute`, `executePrepared`, `raw` and scans. |
| `RedisSessions`            | Service | Leased sessions, `withSession`, `withBlockingSession`, `watch` and blocking commands.        |
| `RedisStreams`             | Service | Continuous stream readers, group consumers and recovery.                                     |
| `RedisScripts`             | Service | Runs a `RedisScript` by digest and loads it on demand.                                       |
| `RedisAdmin`               | Service | Server, ACL, config, client and diagnostics commands.                                        |
| `RedisPubSub`              | Service | `subscribe`, `psubscribe` and `ssubscribe`.                                                  |
| `RedisTracking`            | Service | Client-side caching invalidation stream. Not in the default layer.                           |
| `RedisCache`               | Service | Bounded `GET` cache over `RedisTracking`. Not in the default layer.                          |
| `RedisSearch`              | Service | `aggregate` cursor stream with an owned lease. Needs `RedisSessions`.                        |
| `RedisMonitor`             | Service | `MONITOR` event stream.                                                                      |
| `RedisShutdown`            | Service | `SHUTDOWN`.                                                                                  |
| `RedisCluster`             | Service | Cluster client. Provided by `layerCluster` on a runtime entry point.                         |
| `RedisSentinel`            | Service | Sentinel client. Provided by `layerSentinel` on a runtime entry point.                       |
| `RedisCredentials`         | Service | Credential refresh with `rotate`, `get`, `invalidate`, `revision` and `snapshot`.            |
| `RedisSentinelCredentials` | Service | Credentials for the Sentinel plane.                                                          |
| `CommandExecutor`          | Service | Runs a `Command`. The seam under `Redis`.                                                    |
| `BatchExecutor`            | Service | Runs a batch of commands for pipelines and transactions.                                     |
| `Connection`               | Service | The ordinary connection: `executeOrdinary`, `takePush`, `snapshot`, `close` and `abort`.     |
| `Transport`                | Service | Opens a socket. The runtime entry points provide it.                                         |

### Namespaces

| Export           | Kind      | Purpose                                                                   |
| ---------------- | --------- | ------------------------------------------------------------------------- |
| `Commands`       | Namespace | Every command as a pure `Command` value.                                  |
| `Reply`          | Namespace | Reply decoders such as `blob`, `text`, `integer`, `optional` and `pairs`. |
| `RedisKey`       | Namespace | Typed keys: `make`, `text`, `json`, `schemaText`.                         |
| `PayloadCodec`   | Namespace | Value codecs: `text`, `json`, `schemaText`.                               |
| `StreamPayload`  | Namespace | A single-field stream entry codec.                                        |
| `RedisScript`    | Namespace | `make` builds a script with its SHA-1 digest and reply decoder.           |
| `RedisProfiles`  | Namespace | Deployment profiles for engines and managed providers.                    |
| `RedisTelemetry` | Namespace | `layer(options?)` turns on metrics and spans.                             |

## `@effect-kit/redis/node`

`RedisNode` has six constructors. The `Config` variants take an Effect `Config` of the same input and unwrap it when the layer is built.

| Export                                                                                                       | Kind     | Purpose                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `RedisNode.layer`                                                                                            | Layer    | Standalone client from a `NativeClientInput`. Provides `Redis`, `RedisSessions`, `RedisStreams`, `RedisScripts`, `RedisAdmin`, `RedisPubSub`, `RedisCredentials`, `CommandExecutor`, `BatchExecutor` and `Crypto`. |
| `RedisNode.layerConfig`                                                                                      | Layer    | The same from a `Config<NativeClientInput>`.                                                                                                                                                                       |
| `RedisNode.layerCluster`                                                                                     | Layer    | Cluster client from a `NativeClusterInput`. Provides `Redis`, `RedisCluster`, `RedisCredentials`, `CommandExecutor`, `BatchExecutor` and `Crypto`.                                                                 |
| `RedisNode.layerClusterConfig`                                                                               | Layer    | The same from a `Config`.                                                                                                                                                                                          |
| `RedisNode.layerSentinel`                                                                                    | Layer    | Sentinel client from a `NativeSentinelInput`. Provides `Redis`, `RedisSentinel`, `RedisSentinelCredentials`, `RedisCredentials`, `CommandExecutor`, `BatchExecutor` and `Crypto`.                                  |
| `RedisNode.layerSentinelConfig`                                                                              | Layer    | The same from a `Config`.                                                                                                                                                                                          |
| `Transport`                                                                                                  | Service  | Re-export of the root `Transport`.                                                                                                                                                                                 |
| `connect`                                                                                                    | Function | Open one transport connection.                                                                                                                                                                                     |
| `layer`                                                                                                      | Layer    | The `Transport` layer for Node. It is not a Redis client.                                                                                                                                                          |
| `cryptoLayer`                                                                                                | Layer    | `Crypto` for SHA-1 script digests.                                                                                                                                                                                 |
| `NativeClientInput`, `NativeClusterInput`, `NativeSentinelInput`, `NativeCredentials`, `TransportConnection` | Types    | Input and transport types.                                                                                                                                                                                         |

## `@effect-kit/redis/bun`

The same exports as `./node`, with `RedisBun` in place of `RedisNode` and the Bun transport behind `connect` and `layer`.

| Export                                                                                                        | Kind   | Purpose                               |
| ------------------------------------------------------------------------------------------------------------- | ------ | ------------------------------------- |
| `RedisBun.layer`, `layerConfig`, `layerCluster`, `layerClusterConfig`, `layerSentinel`, `layerSentinelConfig` | Layers | Same as the `RedisNode` constructors. |
| `Transport`, `connect`, `layer`, `cryptoLayer`                                                                | Values | Same as `./node`, for Bun.            |
| `NativeClientInput`, `NativeClusterInput`, `NativeSentinelInput`, `NativeCredentials`, `TransportConnection`  | Types  | Same as `./node`.                     |

## `@effect-kit/redis/upstash`

| Export                                                                                               | Kind      | Purpose                                                                                                                    |
| ---------------------------------------------------------------------------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------- |
| `RedisUpstash.layer`                                                                                 | Layer     | Upstash client over `fetch`. Provides `Redis`, `CommandExecutor`, `BatchExecutor`, `RedisCredentials` and `UpstashEvents`. |
| `RedisUpstash.layerWithHttpClient`                                                                   | Layer     | The same, using the `HttpClient` you provide.                                                                              |
| `RedisUpstash.layerConfig`                                                                           | Layer     | The same from a `Config<UpstashClientInput>`.                                                                              |
| `layer`                                                                                              | Layer     | A simpler preset that takes an `UpstashConfigInput`.                                                                       |
| `makeUpstash`                                                                                        | Function  | Build the Upstash client from `{ url, token, ... }`.                                                                       |
| `decodeUpstashConfig`                                                                                | Function  | Validate an `UpstashConfigInput`.                                                                                          |
| `UpstashEvents`                                                                                      | Service   | `subscribe(channel)` and `monitor()` over server-sent events. Each returns a scoped `{ messages, close }`.                 |
| `UpstashError`                                                                                       | Error     | HTTP failures. Also exported from the root.                                                                                |
| `Commands`                                                                                           | Namespace | Upstash dialect commands for Search, Vector and ACL tokens.                                                                |
| `UpstashClientInput`, `UpstashConfig`, `UpstashConfigInput`, `UpstashMessage`, `UpstashSubscription` | Types     | Input and event types.                                                                                                     |

Upstash has no `RedisSessions`, `RedisStreams`, `RedisScripts`, `RedisAdmin` or `RedisPubSub`. See [Upstash](/docs/redis/runtimes/upstash).
