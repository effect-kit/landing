`RedisNode.layer` and `RedisBun.layer` take one `NativeClientInput`: an address, connection settings, and optional groups for `limits`, `connection`, `sessions`, `subscriptions` and `scripts`. `RedisUpstash.layer` takes an `UpstashClientInput`. Every default below is the value in the package source. Sizes are bytes and times are milliseconds.

**Example** (Changing a Few Defaults)

```ts twoslash
import { RedisNode } from "@effect-kit/redis/node";

export const RedisLive = RedisNode.layer({
  url: "redis://localhost:6379",
  commandTimeoutMillis: 10_000,
  limits: { maxInFlightCommands: 64 },
  sessions: { maxBlockingConnections: 4 },
});
```

## TLS
