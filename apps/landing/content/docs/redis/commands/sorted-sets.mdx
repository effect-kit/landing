title: Sorted sets
description: Look up the sorted set commands, range types and blocking pops with their reply types.
---

Sorted set commands keep members ordered by score. Most score replies are the server's decimal text (`string`), so large and infinite values are not rounded.

**Example** (Ranking Players)

```ts twoslash
import { Effect } from "effect";

import { Redis } from "@effect-kit/redis";

const program = Effect.gen(function* () {
  const redis = yield* Redis;

  yield* redis.zadd("scores", [
    [120, "ada"],
    [95, "grace"],
    [140, "linus"],
  ]);

  const top = yield* redis.zrangeWithScores("scores", {
    //  ^?
    by: "rank",
    start: 0,
    end: 1,
    reverse: true,
  });
  const rank = yield* redis.zrank("scores", "ada");
  //    ^?
  const score = yield* redis.zscore("scores", "ada");
  //    ^?

  return { top, rank, score };
});
```

`zscore` returns `Option<number>`. Use `zscoreToken` to keep the decimal text.

## `SortedRange`

`zrange`, `zrangeWithScores` and `zrangestore` take a `SortedRange`, a union tagged by `by`. `zrangeWithScores` takes `SortedRangeWithScores`, which excludes `by: "lex"`.

<TypeTable
  type={{
    by: {
      type: '"rank" | "score" | "lex"',
      description: "What the range is measured in.",
      required: true,
    },
    start: {
      type: "number | bigint",
      description: "First rank. Rank ranges only.",
      required: false,
    },
    end: { type: "number | bigint", description: "Last rank. Rank ranges only.", required: false },
    min: {
      type: "ScoreBound | LexBound",
      description: "Lower bound. Score and lex ranges only.",
      required: false,
    },
    max: {
      type: "ScoreBound | LexBound",
      description: "Upper bound. Score and lex ranges only.",
      required: false,
    },
    reverse: { type: "boolean", description: "Read from the highest end.", required: false },
    limit: {
      type: "{ offset: number | bigint; count: number | bigint }",
      description: "Page the result. Score and lex ranges only.",
      required: false,
    },
  }}
/>

- `Score` is `number | string`.
- `ScoreBound` is a `Score` or `{ exclusive: Score }`.
- `LexBound` is `"-"`, `"+"` or `{ value: RedisArgument; exclusive?: boolean }`.
- `RangeLimit` is `{ offset; count }`.

## `SortedAddOptions`

`zadd` and `zaddIncrement` take `SortedAddOptions`. `zadd` takes `ScoredMembers`, a non-empty tuple of `[score, member]` pairs.

## Blocking commands

<Callout type="warn" title="Blocking commands need a session">
  `redis.blpop` and the other blocking commands do not exist on `Redis`. They hold a connection
  while they wait, so they live on `RedisSessions` and take `BlockingOptions`. See
  [Sessions](/docs/redis/sessions).
</Callout>

| Method              | Command    | Reply type                                                                  | Purpose                                                                    |
| ------------------- | ---------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| `sessions.bzpopmin` | `BZPOPMIN` | `Option<readonly [Uint8Array, Uint8Array, string]>`                         | Pop the lowest-scored member, waiting if all sets are empty.               |
| `sessions.bzpopmax` | `BZPOPMAX` | `Option<readonly [Uint8Array, Uint8Array, string]>`                         | Pop the highest-scored member, waiting if all sets are empty.              |
| `sessions.bzmpop`   | `BZMPOP`   | `Option<readonly [Uint8Array, readonly (readonly [Uint8Array, string])[]]>` | Pop members from the first non-empty sorted set, waiting if all are empty. |

`redis.zscan` takes a cursor and `ScanOptions` and returns a `ScanPage<readonly [Uint8Array, string]>`. `redis.zscanMembers` sends `NOSCORES`, which is a Valkey option, so other servers can return a `ServerError`. `redis.scanSortedSet` and `redis.scanSortedMembers` stream the whole set. See [Scanning](/docs/redis/scanning).
