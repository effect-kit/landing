A **runtime** layer opens the connection and provides the services. You import exactly one from its own entry point. There is no auto-detection.

| Entry point                 | Layer          | Transport                                   |
| --------------------------- | -------------- | ------------------------------------------- |
| `@effect-kit/redis/node`    | `RedisNode`    | `node:net`, `node:tls`                      |
| `@effect-kit/redis/bun`     | `RedisBun`     | `Bun.connect`                               |
| `@effect-kit/redis/upstash` | `RedisUpstash` | HTTPS and SSE through Effect's `HttpClient` |

## Capability matrix

| Capability                                   | Node.js            | Bun                | Upstash                            |
| -------------------------------------------- | ------------------ | ------------------ | ---------------------------------- |
| Ordinary commands                            | Yes                | Yes                | Yes                                |
| Pipelines and transactions                   | Yes                | Yes                | Yes, one request each              |
| `RedisSessions`, `WATCH`, blocking commands  | Yes                | Yes                | No                                 |
| `RedisPubSub` (binary-safe)                  | Yes                | Yes                | No. Text only with `UpstashEvents` |
| `RedisStreams`, `RedisScripts`, `RedisAdmin` | Yes                | Yes                | No                                 |
| Client-side caching (tracking)               | Yes                | Yes                | No                                 |
| Cluster and Sentinel                         | Yes                | Yes                | No                                 |
| Unix sockets                                 | Yes                | Yes                | No                                 |
| Binary arguments                             | Yes                | Yes                | Limited                            |
| Credential providers and `rotate`            | Yes                | Yes                | Yes                                |
| `delivery` after an uncertain write          | `possibly-written` | `possibly-written` | `unknown`                          |

Client-side caching is available on Node.js and Bun, but it is not part of the layer. You add it yourself.

Deno and Cloudflare Workers support only the Upstash column.
